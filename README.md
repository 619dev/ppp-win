## v1.1.5

- 全新 LiveKit SFU 群组视频会议模式
- 支持主席、全员静音、讲课模式和自由讨论模式
- 完善会议界面与系统通知的多语言支持
- 桌面侧边栏支持搜索用户、发送好友请求
- 联系人列表同时显示好友与群聊，可直接进入会话
- 提供 Windows x64 安装版与免安装便携版

> 视频会议需要服务端启用 `/api/calls/meeting-token` 接口并正确配置 LiveKit。
